# Orbit rules, in the open

This repository explains how [Orbit](https://orbitdiscuss.com) works behind the feed: what is allowed, how moderation decides, and how posts are ranked. It is written to match the code that runs the site. If the two ever disagree, that is a bug, and we treat it as one.

| Document | What it covers |
| --- | --- |
| [Community guidelines](guidelines.md) | What you can and can't post, in plain language |
| [Moderation](moderation.md) | Automatic checks, reports, decisions and appeals |
| [Ranking](ranking.md) | How Hot, New, Top, Rising, For You and comment sorting work |
| [Aura](aura.md) | How members earn aura and what it is used for |
| [Changelog](CHANGELOG.md) | Every change to these rules, with the date |

## Our commitments

- **No secret boosts.** Every ranking signal is listed in [ranking.md](ranking.md). Nobody can pay to rank higher, and there are no promoted posts.
- **People make the final call.** Automatic checks help, but removals, suspensions and appeals are reviewed by a person.
- **You are told why.** If we remove your content or restrict your account, we tell you which rule applied and whether automation was involved.
- **Changes happen in public.** Rule and ranking changes are proposed here, discussed, and recorded in the changelog.

## Propose a change

Anyone can suggest an improvement. Open an [issue](../../issues/new/choose) to start a discussion, or a pull request for wording fixes. See [CONTRIBUTING.md](CONTRIBUTING.md).

The legally binding documents are the [Terms of Service](https://orbitdiscuss.com/terms.html) and [Privacy Policy](https://orbitdiscuss.com/privacy.html). This repository explains them in plain language; it does not replace them.
